
AI.Ind — Personal AI Assistant

AI.Ind adalah aplikasi asisten kecerdasan buatan yang dikembangkan secara mandiri oleh Indri Esti, developer asal Indonesia.

🌐 Website Resmi: https://ai-ind.vercel.app/

Tentang AI.Ind

AI.Ind merupakan proyek pengembangan teknologi Artificial Intelligence (AI) yang dirancang untuk membantu pengguna memperoleh informasi, menjawab pertanyaan, dan mendukung aktivitas sehari-hari.

Fitur Utama

- AI Chat Assistant
- Riwayat Percakapan
- Interaksi dengan Gambar
- AI Video Generator
- Login dan Registrasi Pengguna

Teknologi

- React.js
- JavaScript
- FastAPI
- Python
- SQLite / Turso
- REST API

Pengembang

AI.Ind dikembangkan secara mandiri sebagai proyek eksplorasi dan pengembangan teknologi kecerdasan buatan.
